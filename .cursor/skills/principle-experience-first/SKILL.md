---
name: principle-experience-first
description: Apply when product, UX, or feature-scope tradeoffs come up. Choose user delight over implementation convenience; ship fewer polished features over more rough ones.
---

Every feature, control, and option must be justified. Ship less, ship better. Prototype before committing. Get the details right (transitions, alignment, spacing, feedback, error states). Tighten the core loop. The user is whoever consumes the work, including the next maintainer.
